# Cameron Parker

Independent AI systems operator based in Maple Bay, British Columbia.

I build and operate self-hosted AI agents, local model infrastructure, and practical automations. My work is terminal-first and runs across Linux servers, virtual machines, messaging gateways, cloud-model APIs, and NVIDIA GPU hardware.

## Current focus

- Reliability and recovery for long-running AI agents
- Human approval and tool-permission boundaries
- Local and private model serving
- Failure testing across agent harnesses, tools, memory, and infrastructure
- Useful AI systems for small businesses and nontechnical users

## Operating environment

Linux · SSH · Docker · systemd · Git · JSON/YAML · SQLite · APIs/webhooks · NVIDIA/CUDA · Ollama · local and hosted language models

My Python skills are developing. I use AI coding agents for implementation support while I define requirements, operate the systems, test failure cases, and review evidence.

## Selected work

- [From chatbot to operator](https://github.com/cameronparkerai/recoverable-agent-systems) — lessons from operating isolated agents and building toward recoverable, human-controlled systems
- [Maple Bay House](https://maplebayhouse.com) — a hospitality property and direct-booking operation where I apply automation to communications, scheduling, records, and administration

## Research direction

I am interested in empirical evaluations for agents operating under degraded conditions: gateway restarts, stale memory, partial tool results, network timeouts, duplicate-action risk, and incomplete authorization. The goal is to make capable agents observable, recoverable, and safe enough for broader everyday use.
